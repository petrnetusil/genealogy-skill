# Family tree project

This is a family tree project guided by the **genealogy** skill. At the start of every conversation:
1. Load the `genealogy` skill (if it is not loaded yet).
2. Read `data/STATUS.md` – status, rules and work in progress – and the end of `data/research_log.md`.
3. Continue where the work stopped. Communicate in the user's language, briefly and clearly for someone without experience
   in genealogy or programming.
4. Network access to archive websites only through the brake `tools/polite.py` (own scripts, curl), also in the
   instructions for helpers – see the skill, "Being gentle with archives".
5. Write anything that could improve the skill (tool bugs, new archives, ideas) into `notes_for_skill.md` – see the skill,
   section "Notes for the skill maintainer".
